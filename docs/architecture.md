# Architecture

## Project Structure

- `apps/` — Django applications
- `config/` — project configuration
- `media/docs/` — uploaded user files
- `templates/` — shared templates
- `docs/` — project docs
- `requirements/` — dependency management

## Core Apps

### documents
Responsible for:
- document upload
- storage
- retrieval
- metadata management

### accounts
Responsible for:
- user accounts


### applications
Responsible for:
- creating and modifying applications


### companies
Responsible for:
- creating and modifying companies


### workspaces
Responsible for:
- creating and modifying workspaces
